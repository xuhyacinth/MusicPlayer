# README 学习指南设计

## 背景

项目现有 `README.md` 为空。仓库是一个基于 Java、SWT、Java Sound 和 SQLite 的本地音乐播放器，包含 MP3/FLAC 解码、LRC 歌词同步、FFT 频谱展示、播放列表持久化和系统托盘等实现，适合作为桌面音频开发的学习项目。

## 目标

面向希望阅读和学习源码的开发者编写 README，使读者能够：

1. 在正确的环境中构建并运行项目。
2. 理解从歌曲选择到音频输出、频谱绘制和歌词刷新的完整调用链。
3. 将 SWT、Java Sound、FFT、LRC 和 SQLite 等知识对应到具体源码。
4. 了解当前实现的边界，并找到进一步练习和改进的方向。

## 非目标

- 不把 README 写成逐行源码解释。
- 不扩展或修改播放器功能。
- 不宣称未经项目配置和验证的平台兼容性。
- 不加入与当前代码无关的通用音频理论。

## 内容组织

README 采用“学习路径为主、技术专题索引为辅”的结构：

1. 项目简介与功能概览。
2. 环境要求、构建、测试和运行命令。
3. 项目目录及核心类职责。
4. 播放主链路和数据流。
5. 核心知识专题：
    - SWT 事件循环与 UI 线程；
    - Java Sound、PCM 与 `SourceDataLine`；
    - MP3/FLAC 解码 SPI；
    - FFT 频谱计算和 SWT 绘制；
    - LRC 时间标签解析与同步；
    - SQLite 表结构、反射映射和查询封装；
    - 虚拟线程、共享状态和定时刷新；
    - Maven Shade 打包与资源加载。
6. 数据库模型。
7. 测试现状、已知限制和后续学习建议。

## 事实边界

文档内容以当前仓库为准，并明确以下约束：

- Maven 编译目标为 Java 25。
- SWT 依赖是 Windows x86_64 版本，当前构建不能直接视为跨平台版本。
- 主入口是 `com.xu.music.player.main.MusicPlayer`。
- 数据库固定使用相对路径 `lib/sqlite/db/MusicPlayer.db`，运行目录会影响数据库定位。
- Maven Surefire 默认配置为跳过测试，需要显式使用 `-DskipTests=false` 执行测试。
- Shade 插件生成包含 Java 依赖和图片资源的可执行 JAR，但数据库与歌曲仍是外部文件。
- 文件选择器接受 MP3、WAV、FLAC 和 PCM；实际可解码能力还受 Java Sound SPI 和音频编码格式影响。

## 表达方式

- 使用简体中文。
- 命令保持可复制，并注明应在项目根目录执行。
- 使用一个简洁的 Mermaid 流程图描述主调用链。
- 每个知识点提供“原理、项目中的落点、阅读入口”，避免堆砌定义。
- 对已知缺陷或不一致使用客观描述，不把预期行为写成已验证能力。

## 验证

完成 README 后执行以下检查：

1. 重新运行 `mvn -q package`。
2. 运行 `mvn -q -DskipTests=false test`。
3. 检查生成的 Shade JAR、主类及图片资源。
4. 检查 README 中引用的文件、目录、命令和数据库表名是否存在。
5. 检查 Git 差异，确保不修改业务代码或覆盖无关用户改动。
